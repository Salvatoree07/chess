
# LET'S PLAY CHESS! ♟️

A Java-based chess game featuring a graphical user interface, player profiles, match history tracking, and a complete implementation of standard chess pieces and rules.

---

## ✨ Game Features

* **Interactive Graphical Interface:** Built with Java, featuring custom graphics and piece assets for an immersive chess experience.
* **Player Management & Profiles:** Set custom player names and track user profiles within the application.


* **Match History Tracking:** Automatically logs game outcomes and stats to a text-based history file (`storico.txt`).


* **Complete Chess Logic:** Full implementation of standard chess pieces (Pawn, Rook, Knight, Bishop, Queen, King) with respective movement rules and mechanics (such as promotion and draws/stalemates).


* **User-Friendly Controls:** Smooth mouse interaction for piece movement and intuitive menu navigation (Home screen, exit confirmation, etc.).

## ⚙️ Setup & Configuration

Before running the application, please ensure you complete the following steps:

1. **Configure the Resource Path:**
* Open the `Game` class (the main entry point containing the `main` method).


* Locate the `path` string variable and update its value to point correctly to the `res` folder where game assets and text files are stored.


* You can use a relative path like `..\Chess\src\res\` or an absolute path like `C:\Users\Utente\Documents\NetBeansProjects\Chess\src\res\`.


2. **Clear the Match History:**
* Empty the contents of the `storico.txt` text file located in the resources directory to start fresh.





---

## 🚀 Running the Game

1. Open the project inside your preferred IDE (NetBeans or VS Code with Java extensions installed).


2. Navigate to the `Game` class (the file containing the `main` method).


3. Click the **Run File** button in your IDE to launch the application.
